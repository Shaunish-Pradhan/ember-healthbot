# Ember Healthbot

A prototype for a mental health application that sends interactive notifications to you, checking up on your physical and mental well-being and which can pull up the entire application and talk to you if prompted. Just as like a friend or an automated therapist to those without the privilege of being able to afford one, while needing the help.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://ember-healthbot.lovable.app
